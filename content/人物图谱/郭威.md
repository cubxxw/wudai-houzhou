# 郭威

> <abbr tabindex="0" title="古人本名之外的别称，多用于平辈或尊长称呼。「文仲」二字寓「文德仲昭」，与其武人出身形成对照。">字文仲</abbr>。邢州尧山人。颈刺飞雀，人称"**郭雀儿**"。后周开国皇帝，<abbr tabindex="0" title="即皇帝死后在太庙立室奉祀时所追尊的名号。「太祖」即开国之祖，是开国皇帝最常用的庙号。">庙号</abbr>太祖。
> 一句话：**一个被乱世规则碾到底的人，最后决定不再按那套规则活。**

## 身世坐标
- 父 **郭简**，曾任顺州刺史，郭威约三岁时死于兵祸；母王氏早亡。由**姨母韩氏**抚养，少孤而贫。
- 关于本姓，《旧五代史》有"或云本常氏之子"之异闻，官方则称"虢叔之后"（详见 [[史料考据档案]]）。

## 一生四段
1. **潜龙**：投[[李继韬]]为牙兵 → 醉杀屠者下狱获释 → 后唐亲军"从马直"军吏，读《阃外春秋》。
2. **佐命**：娶[[圣穆皇后柴氏|柴氏]]；历[[石敬瑭]]、[[刘知远]]帐下；947 助刘知远建后汉，任枢密副使。
3. **崛起**：948 升枢密使；949 火攻破河中[[李守贞]]，威望大著。
4. **逐鹿**：950 [[后汉隐帝刘承祐|隐帝]]灭其满门 → 举兵 → 澶州兵变黄袍加身 → 951 建周称帝 → 三年改革 → 954 薄葬嵩陵。

## 关键关系

- 失子之痛：[[郭威诸子]]

## 性格底色
谨厚、能容、识人、重旧情；早年好酒赌斗狠，因柴氏规劝渐自敛。最大特征是**对权力的警惕**——他亲历了金玉如何招来杀身、藏陵如何招来发掘，于是当庭碎玉、遗令纸衣瓦棺。
